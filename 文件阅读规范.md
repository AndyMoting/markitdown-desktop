# 文件阅读规范

以后读文件按这个来。

## 万能方案：markitdown

一行代码通吃 PDF、DOCX、PPTX、XLSX、XLS、HTML、CSV、JSON、XML、TXT、图片、邮件、EPUB、ZIP。90% 的文件这个就够了。

```bash
pip install "markitdown[all]"
```

```python
from markitdown import MarkItDown
md = MarkItDown()
结果 = md.convert("文件路径")
print(结果.text_content)
```

**批量转换时复用实例**，别每个文件 new 一次：

```python
md = MarkItDown()
for 文件 in 文件列表:
    print(md.convert(文件).text_content)
```

## 按格式分包

markitdown 搞不定的才用下面的。

### PDF

```bash
pip install pdfplumber PyMuPDF
```

| 库 | 用途 | 说明 |
|----|------|------|
| pdfplumber | 文字+表格 | 结构化 PDF |
| PyMuPDF (fitz) | 文字+内嵌图片 | 中日韩文字更好 |

```python
# 提取文字+表格
import pdfplumber
with pdfplumber.open("文件.pdf") as pdf:
    for page in pdf.pages:
        print(page.extract_text())
        print(page.extract_tables())

# 提取文字（中文首选）
import fitz
doc = fitz.open("文件.pdf")
for page in doc:
    print(page.get_text())
doc.close()
```

### Word (.docx)

```bash
pip install python-docx mammoth
```

```python
# 读段落+表格
from docx import Document
doc = Document("文件.docx")
for p in doc.paragraphs:
    print(p.text)

# 转 Markdown
import mammoth
with open("文件.docx", "rb") as f:
    结果 = mammoth.convert_to_markdown(f)
    print(结果.value)
```

### PPTX

```bash
pip install python-pptx
```

```python
from pptx import Presentation
prs = Presentation("文件.pptx")
for slide in prs.slides:
    for shape in slide.shapes:
        if shape.has_text_frame:
            print(shape.text)
        if shape.has_table:
            for row in shape.table.rows:
                print([c.text for c in row.cells])
```

### Excel

```bash
pip install openpyxl xlrd pandas
```

```python
import pandas as pd

# 读所有 sheet
所有表 = pd.read_excel("文件.xlsx", sheet_name=None)
for 表名, 数据 in 所有表.items():
```

### CSV / JSON / XML / TXT

标准库，不用额外安装。

```python
# CSV
import csv
with open("文件.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row)

# JSON
import json
数据 = json.load(open("文件.json", encoding="utf-8"))

# XML
from xml.etree import ElementTree
tree = ElementTree.parse("文件.xml")

# TXT（先试 UTF-8，不行用 chardet 猜编码）
with open("文件.txt", encoding="utf-8") as f:
    内容 = f.read()
```

## 速查表

| 文件后缀 | 库 | 读法 |
|---------|----|------|
| .pdf | pdfplumber / PyMuPDF | 看上面 PDF 一节 |
| .docx | python-docx / mammoth | `Document()` 或 `mammoth.convert_to_markdown()` |
| .doc | aspose-words-foss | 先转 .docx 再读 |
| .pptx | python-pptx | `Presentation()` |
| .xlsx | openpyxl / pandas | `pd.read_excel()` |
| .xls | xlrd / pandas | 同上 |
| .html | beautifulsoup4 | `BeautifulSoup(open(), "lxml")` |
| .csv | stdlib csv | `csv.DictReader()` |
| .json | stdlib json | `json.load()` |
| .xml | stdlib xml.etree | `ElementTree.parse()` |
| .txt | stdlib | `open().read()` |
| .jpg/.png/... | Pillow | `Image.open()` |
| .eml | mail-parser | `parse_from_file()` |
| .epub | ebooklib + bs4 | `epub.read_epub()` |
| .zip | stdlib zipfile | `ZipFile()` |
| 所有以上 | **markitdown** | `MarkItDown().convert()` |

## 规则

1. 先试 markitdown，不行再找专用库
2. 中文 PDF 优先 PyMuPDF
3. 批量处理复用 MarkItDown 实例，不要每个文件 new 一次
4. 用 `with` 或 `.close()` 关文件
5. 读文本文件先试 `encoding="utf-8"`，不行再用 chardet 猜
6. 不要读二进制文件的原始字节，用专门的库解析
